# 余量 Phase 4 至 Phase 10 实施计划

1. Phase 4：首页聚合层、四栏导航、无计划/正常/预警/风险/预测不足状态。
2. Phase 5：快速记账、账单搜索筛选、详情、编辑删除、分类归档。
3. Phase 6：分类统计、每日趋势、预测、风险与文字摘要。
4. Phase 7：完整 JSON 备份、CSV 导出、真实文件校验、分享、原子恢复。
5. Phase 8：Design/Motion Tokens、物理按钮、胶囊记账、Rolling Number、可复用 Sheet、Reduce Motion。
6. Phase 9：容器过渡、图表磁吸、轻量交错、3D Tilt、Budget Glow、低性能降级。
7. Phase 10：32 项回归测试、Lint、1.0.0 版本、私钥签名入口、Release APK/AAB。

阶段 4 至 9 已完成源码实现。阶段 10 的代码和配置已完成，但实际 Build/Test/Lint/签名产物因当前环境无法下载 Gradle 且缺少 Android SDK 而停在最终验证门槛。
